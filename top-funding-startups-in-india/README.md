🚀 Top Funding Startups in India

A Streamlit-based interactive dashboard for analyzing startup funding trends in India. This project provides insights into funded startups, investment patterns, funding distribution, top investors, and predictive analytics using machine learning.

📌 Features
📊 Dataset Overview
📈 Interactive Visualizations
💰 Funding Trend Analysis
🏙️ City-wise Funding Distribution
🏢 Top Funded Startups
🤝 Top Investors Analysis
🔮 Funding Prediction using Machine Learning
📋 Business Insights Dashboard
